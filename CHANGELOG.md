# Changelog

## 1.0 — 2026-10-08

First public edition, based on the internal v1.3.E development build.

- Direct loading of compatible, uncompressed SPC files from FAT32 microSD.
- Checked C700 and game-driver compatibility; unsupported files return error 67.
- Folder navigation, held-button repeat, wrapping, previous/next track and Stop
  without RESET. B changes folders while keeping playback active.
- Volume, pitch-preserving tempo, and MONO/STEREO on supported drivers.
- Stereo meters, eight voice meters and sparse DSP OUTX traces.
- Eight player/information pages with DSP observations and ID666 metadata.
- English HUD, animated presentation, logo sound, loading progress and navigation
  sound while music is stopped.
- HiROM FastROM and LoROM alternatives, both 4 MiB.
- Public version 1.0 in filenames, HUD and internal ROM titles.
- Portable source build, English/Spanish guides, error reference, compatibility
  catalog, credits and checksums.

This numbering starts the public release series; it does not imply new driver
support beyond the internal v1.3.E build.
